CoGA Reporting & traceability

From reviewed variants to a signed, traceable report

Every reported result is locked to the exact software, annotation and reference versions that produced it — then sealed in a tamper-evident audit trail.

03 / 07
1 · Review
ACMG/AMP classification
semi-automatic 5-class score, recomputed server-side; every criterion overridable
Tags & notes
the report tag selects variants; who/when + analyst note
Evidence snapshot
frozen at each save: annotation-set-hash · ClinVar · timestamp
2 · Gating
Classification-drift
frozen vs current annotation-set-hash — 409 unless acknowledged
Sample-QC acknowledgement
sex · relatedness · Mendelian · NIPT + swap checks — blocks unless acknowledged with a reason
3 · Sign-out
Frozen versioned snapshot
SHA-256 content-hashed, append-only; amendments create a new version — prior versions never mutate
Bound to three version axes
sw build + git_sha ann manifest + set-hash ref assembly
4 · Outputs
Signed report
variant sections · gene & HPO context · provenance footer (VEP · ClinVar · gnomAD · HPO …) · PDF export
Hash-chained audit
append-only before/after log; each entry's row_hash links to the prior — edits/reordering become detectable
seal Ed25519 integrity anchors
In-house IVD · IVDR Art 5(5). The chain is tamper-evident against a database-only adversary between retained anchors, not tamper-proof. ACMG/AMP output is decision support — confirmed by a qualified clinical scientist before clinical use.
